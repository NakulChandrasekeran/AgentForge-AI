
# AgentForge AI

### Enterprise Multi-Agent Research Platform

AgentForge AI is a full-stack, locally hosted AI research platform
that uses four specialized AI agents to transform research questions
into structured reports.

Built with Python, FastAPI, LangGraph, Ollama, React, and TypeScript.

## Features

- Four specialized AI agents
- Multi-agent workflow orchestration with LangGraph
- Local LLM inference using Ollama and Qwen3
- Research and analysis through a FastAPI backend
- Evidence and consistency review
- Structured Markdown report generation
- Interactive React dashboard
- Individual tabs for agent outputs
- Downloadable Markdown reports

## AI Agent Architecture

User Research Question
        |
        v
Research Agent
        |
        v
Analysis Agent
        |
        v
Verification Agent
        |
        v
Report Agent
        |
        v
Structured Research Report

### Research Agent
Generates research content relevant to the user's question.

### Analysis Agent
Analyzes the research and identifies key findings,
limitations, and implications.

### Verification Agent
Reviews generated content for unsupported claims,
uncertainties, and internal consistency.

Note: This agent does not independently verify claims
against external sources.

### Report Agent
Combines the workflow outputs into a structured report
with findings, analysis, limitations, and recommendations.

## Installation
NakulChandrasekeran
### Prerequisites

- Python 3.13
- Node.js and npm
- Ollama
- Git

### 1. Clone the repository

git clone https://github.com/YOUR_USERNAME/AgentForge-AI.git

cd AgentForge-AI

Replace YOUR_USERNAME with your GitHub username.

### 2. Install Ollama and download the model

ollama pull qwen3:1.7b

Ensure Ollama is running locally.

### 3. Set up the backend

cd backend

python -m venv .venv

On Windows PowerShell:

.\.venv\Scripts\Activate.ps1

Install dependencies:

python -m pip install -r requirements.txt

Start the backend:

python -m uvicorn app.main:app --reload

Backend URL:
http://127.0.0.1:8000

API documentation:
http://127.0.0.1:8000/docs

### 4. Set up the frontend

Open a second terminal.

cd frontend

npm install

npm run dev

Frontend URL:
http://localhost:5173

## API Endpoints

GET /health
Check backend health.

GET /api/agents
List available AI agents.

POST /api/research
Run the multi-agent research workflow.

Example request:

{
  "question": "What are the benefits and risks of multi-agent AI systems?"
}

## Current Limitations

- Research is generated by a local language model.
- No external web retrieval or independent fact-checking.
- Model responses may contain inaccurate information.
- Execution speed depends on local hardware.
- No persistent research history.
